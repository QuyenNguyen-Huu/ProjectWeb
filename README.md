---

## 🌟 Tính năng nổi bật (Key Features)

- **🤖 AI Chatbot Thông minh**: Tích hợp thư viện React chuyên dụng, hỗ trợ tư vấn khách hàng và xử lý giao tiếp API thời gian thực với hệ thống Cloud.
- **🌐 Hỗ trợ Đa ngôn ngữ (Bilingual)**: Hệ thống được thiết kế hỗ trợ chuyển đổi ngôn ngữ (Tiếng Việt/Tiếng Anh) linh hoạt cho cả giao diện và dữ liệu.
- **⚡ Kiến trúc Serverless**: Toàn bộ logic Backend được vận hành trên nền tảng Serverless, giúp hệ thống tự động mở rộng và tối ưu chi phí vận hành.
- **📱 Thiết kế Responsive**: Giao diện hiển thị tối ưu trên mọi kích thước màn hình từ Desktop đến Mobile.
- **🔍 Bộ lọc & Tìm kiếm Nâng cao**: Tìm kiếm toàn cầu kết hợp bộ lọc thông minh theo thương hiệu, giá và kích thước sản phẩm.

## 🏗️ Kiến trúc Hệ thống (AWS Cloud Architecture)

Dự án tận dụng sức mạnh của hệ sinh thái **Amazon Web Services (AWS)** để đảm bảo tính ổn định và bảo mật:

- **AWS Lambda**: Xử lý các nghiệp vụ Backend (Serverless functions).
- **API Gateway**: Quản lý, điều phối và bảo mật các luồng gọi API.
- **AWS S3**: Lưu trữ hình ảnh sản phẩm và triển khai Hosting cho ứng dụng React.
- **AWS IAM**: Quản lý phân quyền và bảo mật tài nguyên đám mây chặt chẽ.
- **Database on Cloud**: Hệ thống cơ sở dữ liệu được lưu trữ và vận hành trực tiếp trên hạ tầng AWS.

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **Frontend**: React 18, Vite, Tailwind CSS.
- **Backend**: Node.js, Express.
- **Cloud**: AWS Lambda, API Gateway, S3, IAM, CloudFront.
- **Công cụ**: Git, GitHub, Postman.
